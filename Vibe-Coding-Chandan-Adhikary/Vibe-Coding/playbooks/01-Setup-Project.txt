01-Setup-Project
================

Purpose: Bootstrap Vibe Coding in a new or existing project with working IDE commands, hooks, docs, and verification.
Read trigger: MUST read immediately before setting up or copying this framework into a project.
Applicability: Vibe Coding

Prerequisites:
- Copy framework files to the **workspace/git root** (IDEs discover `.agents/` at the repo root, not nested subfolders).
- Read `AGENTS.md`, `docs/INDEX.md`, `docs/ide-compatibility.md`, and `LICENSE-DECISION.md`.

Commands & Skills:
- Commands: `/plan-ca-agent`, `/dashboard-ca-agent`, `/spec-check-ca-agent`
- Skills: `andrej-karpathy-skill`, `requirements-analysis`, `prd-writer`

Procedure:
1. Initialize IDE adapters and project docs:
   - Run: `python scripts/init_project.py --ides antigravity` (or `--ides all` / `--ides claude,cursor,windsurf,copilot`).
   - Pass `--clean-samples` to remove `001-example-feature.md` for a fresh project.
   - Pass `--install-git-hooks` after `git init` to enable local pre-commit checks.
2. Define product & governance baseline:
   - Populate `docs/product.md`, `docs/prd.md`, `docs/tech-stacks.md`, and `docs/environments.md`.
   - Record license choice per `LICENSE-DECISION.md` and create `.env` from `.env.example` (never commit secrets).
3. Verify setup:
   - Run: `python scripts/check_docs.py`
   - Run: `python scripts/manifest.py --check`
   - Optional: launch In-IDE Mission Control with `/dashboard-ca-agent` (`Project-Manager-Dashboard/open-in-ide.bat` or `.sh`).

Required output:
- Clean `check_docs.py` output (0 errors), active IDE slash commands in `/` dropdown, and initialized `docs/product.md` + `docs/prd.md`.
- MUST stop at missing approval, unresolved policy conflict, or unsafe credentials.
