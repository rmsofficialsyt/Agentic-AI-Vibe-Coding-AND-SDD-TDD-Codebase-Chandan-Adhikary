07-Testing-QA
=============

Purpose: Execute the Vibe Coding test and QA checks and map every acceptance criterion to passing test evidence.
Read trigger: MUST read before running QA suites or signing off on feature verification.
Applicability: Vibe Coding

Prerequisites:
- Read `docs/code-testing.md`, `docs/acceptance-criteria.md`, and `docs/accessibility.md`.
- Confirm every `AC-FEAT###-##` has a `TEST-FEAT###-##` mapping in `docs/features/`.

Commands & Skills:
- Commands: `/tdd-ca-agent`, `/testing-ca-agent`, `/verify-ca-agent`
- Skills: `tdd-enforcer`, `accessibility-auditor`, `ui-fidelity-review`, `ml-evaluation`

Procedure:
1. Run Targeted & Suite Tests:
   - Run `/testing-ca-agent` for unit, integration, API contract, and E2E tests.
   - Never relax assertions or skip failing tests to force green output.
2. Specialized Quality Gates (when applicable):
   - UI changes: run `accessibility-auditor` and `ui-fidelity-review`.
   - ML/AI changes: run `ml-evaluation`.
3. Traceability & Docs Verification:
   - Run `python scripts/check_docs.py` and `/verify-ca-agent`.

Required output:
- Exact commands executed, raw pass/fail counts, coverage/gate status, and updated `docs/task.md`.
