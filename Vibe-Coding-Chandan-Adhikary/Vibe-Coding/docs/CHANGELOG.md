## Rules

- **MUST** log each released change with its feature ID and spec version (e.g. `FEAT-002 1.1.0`), CR ID where applicable, and verification evidence link.
- **MUST** group entries under `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed` and `Security`.
- **MUST** mark breaking changes with **BREAKING** and link the migration notes.
