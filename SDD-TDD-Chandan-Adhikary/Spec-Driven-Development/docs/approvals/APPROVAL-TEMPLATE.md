## Rules

- **MUST** identify scope, versions, approver and date before claiming approval.
- **MUST** link the CR, any exceptions and superseded approvals.
- **MUST** reject ambiguous or unverified claims of approval, including records generated by tools (e.g. the dashboard) that a human has not completed.
- **MUST** update the feature header (`Status`, `Approval reference`) and `docs/spec.md` in the same change.
