04-Authentication-Security
==========================

Purpose: Enforce authentication, authorization, secret hygiene, and security auditing across SDD changes.
Read trigger: MUST read before implementing auth, RBAC, session/token handling, or handling secrets.
Applicability: SDD

Prerequisites:
- Read `docs/security.md`, `docs/apis.md`, and the approved `FEAT-###` spec.
- Ensure `.env` is gitignored and only `.env.example` contains placeholder keys.

Commands & Skills:
- Commands: `/security-audit-ca-agent`, `/spec-check-ca-agent`, `/tdd-ca-agent`, `/review-ca-agent`
- Skills: `security-auditor`, `api-contract-review`, `code-reviewer`

Procedure:
1. Threat & Boundary Check:
   - Verify authn/authz rules, tenant isolation, input validation, and rate limits in `docs/security.md` and the feature spec.
2. Secret & Hook Hygiene:
   - Confirm `.agents/hooks.json` (`pre_tool_guard.py`) is active and no credentials exist in code, logs, or `docs/`.
3. Security TDD:
   - Write failing negative tests (unauthenticated `401`, cross-tenant/unauthorized `403`/`404`, malformed tokens, injection payloads).
4. Audit:
   - Run `/security-audit-ca-agent` (skill: `security-auditor`) and fix all Critical/High findings before merge.

Required output:
- Passing security/negative tests, `/security-audit-ca-agent` report with zero unresolved Critical/High issues.
