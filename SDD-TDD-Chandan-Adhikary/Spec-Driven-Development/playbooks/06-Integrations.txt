06-Integrations
===============

Purpose: Design, contract-test, and harden third-party APIs, webhooks, and database/service integrations.
Read trigger: MUST read before adding or changing external API clients, webhooks, or schema migrations.
Applicability: SDD

Prerequisites:
- Read `docs/apis.md`, `docs/database.md`, `docs/dependencies.md`, and approved `FEAT-###`.

Commands & Skills:
- Commands: `/spec-check-ca-agent`, `/tdd-ca-agent`, `/implement-ca-agent`, `/verify-ca-agent`
- Skills: `api-contract-review`, `database-migration-review`, `performance-profiler`

Procedure:
1. Contract & Schema Alignment:
   - Update `docs/apis.md` and `docs/database.md` (with rollback-safe migrations) per approved spec.
2. Resilience Controls:
   - Enforce explicit timeouts, bounded retries with backoff, idempotency keys, and signature verification on webhooks.
3. Contract & Integration Tests:
   - Run `/tdd-ca-agent` with mocked/sandboxed upstream responses, timeout simulations, and error mapping tests.
4. Dependency & Docs Check:
   - Verify package names/versions in `docs/dependencies.md` and run `python scripts/check_docs.py`.

Required output:
- Passing contract/integration tests, updated `docs/apis.md` / `docs/database.md`, and `check_docs.py` pass.
