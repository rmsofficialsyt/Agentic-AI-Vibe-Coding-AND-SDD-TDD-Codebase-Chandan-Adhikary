02-Project-Implementation
==========================

Purpose: Execute SDD implementation strictly from an APPROVED feature specification using TDD.
Read trigger: MUST read before writing any production code in SDD.
Applicability: SDD

Prerequisites:
- Feature spec in `docs/features/` MUST have `Status: APPROVED` and a valid `APR-###` record in `docs/approvals/`, and MUST be indexed in `docs/spec.md`.
- Task MUST be `READY` in `docs/task.md` with allowed files and acceptance criteria (`AC-FEAT###-##`).

Commands & Skills:
- Commands: `/spec-check-ca-agent`, `/plan-ca-agent`, `/task-ca-agent`, `/tdd-ca-agent`, `/implement-ca-agent`, `/verify-ca-agent`, `/review-ca-agent`
- Skills: `spec-validator`, `task-planner`, `tdd-enforcer`, `andrej-karpathy-skill`, `code-reviewer`

Procedure:
1. Authority & Spec Check:
   - Run `/spec-check-ca-agent` (skill: `spec-validator`) against the target `FEAT-###` in `docs/features/` and `docs/spec.md`.
   - Stop immediately if the feature is `DRAFT` or `IN REVIEW` without `APR-###`.
2. Plan & Task Decomposition:
   - Run `/plan-ca-agent` and `/task-ca-agent` (skill: `task-planner`) to confirm `TASK-###` scope and allowed files in `docs/task.md`.
3. Red-Green-Refactor (TDD):
   - Run `/tdd-ca-agent` (skill: `tdd-enforcer`): write failing tests (`TEST-FEAT###-##`) mapped to each `AC-FEAT###-##` and verify they fail for the right reason.
   - Run `/implement-ca-agent`: write minimal production code within allowed files until tests pass.
4. Verify & Review:
   - Run `/verify-ca-agent`, `python scripts/check_docs.py`, and `/review-ca-agent` (skill: `code-reviewer`).

Required output:
- Passing test suite output, updated `docs/task.md`, and real command evidence.
- MUST stop if tests are skipped, spec is unapproved, or scope drifts outside allowed files.
