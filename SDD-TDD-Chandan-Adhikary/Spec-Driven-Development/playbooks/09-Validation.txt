09-Validation
=============

Purpose: Run objective pre-merge and pre-release validation gates across code, specs, docs, and manifest.
Read trigger: MUST read before opening a PR, merging, or advancing a release phase.
Applicability: SDD

Prerequisites:
- Read `docs/code-review.md`, `docs/release-checklist.md`, `docs/phases.md`, and `docs/requirements-traceability.md`.

Commands & Skills:
- Commands: `/spec-check-ca-agent`, `/verify-ca-agent`, `/review-ca-agent`, `/release-check-ca-agent`
- Skills: `spec-validator`, `release-validator`, `documentation-sync`, `code-reviewer`

Procedure:
1. Documentation & Manifest Gates:
   - Run: `python scripts/check_docs.py`
   - Run: `python scripts/manifest.py --check` (or `generate` if package files changed intentionally).
2. Spec & Code Gates:
   - Run `/spec-check-ca-agent`, `/verify-ca-agent`, and `/review-ca-agent`.
3. Release Gate (before phase exit or deploy):
   - Run `/release-check-ca-agent` (skill: `release-validator`) against `docs/release-checklist.md` and `docs/phases.md`.
   - Record human phase exit approval (`APR-###`) in `docs/approvals/`.

Required output:
- Zero errors from `check_docs.py` and `manifest.py --check`, passing CI/test evidence, and recorded approval.
